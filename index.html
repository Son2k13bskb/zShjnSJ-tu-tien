▶ Mô phỏng: người dùng chat thì bot trả gì?

Mô phỏng message theo cách bot hiện ra trong Discord: user gửi command → reply context → bot zShinSJ (APP) trả Components V2. Nội dung số liệu là minh hoạ.

Không phải ảnh mockup chết: khung này đổi theo từng ví dụ bằng JavaScript. Nhân loại cuối cùng cũng tìm ra cách làm một cái wiki biết đổi nội dung. 🎴

⚠ Ghi chú đối chiếu source

Những điểm trang này cố tình giữ nguyên thay vì tự ý “sửa hộ” code.

1. Prefix: source lọc message.content.startsWith('.'), vì vậy prefix thực tế ở bản code này là ..

2. Cảnh giới: mảng REALMS có 35 entry, trong khi option mô tả trong buffnhe vẫn ghi “Cảnh Giới (Index 0-29)”. Trang wiki ưu tiên dữ liệu REALMS thực tế và giữ lại ghi chú này để bạn biết source còn lệch metadata.

3. Slash: source có 17 slash command chính. Một số command slash trùng chức năng với prefix, ví dụ /luyendan, /thongtin, /pay.

4. UI: bot đang dùng Components V2 với ContainerBuilder, TextDisplayBuilder, SectionBuilder, SeparatorBuilder và MessageFlags.IsComponentsV2. Đây là lý do phần mô phỏng chat trình bày theo kiểu panel/card thay vì Embed cổ điển.
